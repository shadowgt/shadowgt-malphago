앱 이름: 말파고 - AI 경마 예측

짧은 설명 (80자):
AI가 분석하는 스마트 경마 예측! 말-기수 시너지, 거리적성, 실시간 변경 알림

전체 설명:
말파고(MalPhaGo)는 인공지능 기반 경마 예측 앱입니다.

■ 주요 기능

▶ AI 예측
• LightGBM/XGBoost 머신러닝 모델 기반 예측
• 15개 분석 요인 종합 점수 산출
• 시계열 교차검증으로 검증된 모델 정확도

▶ 상세 분석
• 말 분석: 거리적성, 주로적성, 최근 폼, 마체중 변동
• 기수 분석: 트랙 특화도, 거리별 승률, 피로도
• 시너지 분석: 말-기수 조합, 조교사-기수 조합 이력
• 등급 꼼수 감지: 의도적 등급 조정 패턴 탐지

▶ 실시간 정보
• 경주일 출주표 실시간 업데이트
• 기수/말 변경 즉시 알림 (FCM 푸시)
• 변경 시 자동 재예측

▶ 편리한 기능
• 경마장별(서울/부산/제주) 경주 목록
• 예측 순위 + 비교 모드
• 과거 예측 적중률 이력

■ 프리미엄 구독
• 광고 제거
• 상세 분석 리포트
• 실시간 예측 알림
• 경주일 SMS 예측 전송

■ 데이터 출처
한국마사회(KRA) 공식 데이터 및 검빛(Gumbit) 통계 기반

■ 주의사항
본 앱의 예측은 참고용이며, 실제 베팅에 대한 책임은 사용자에게 있습니다.
