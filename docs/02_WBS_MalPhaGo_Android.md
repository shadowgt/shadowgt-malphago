## 리스크 관리

| 리스크 | 영향 | 대응 |
|--------|------|------|
| KRA/Gumbit 사이트 구조 변경 | 크롤링 실패 | 크롤러 테스트 자동화, 구조 변경 알림 |
| KRA 접근 차단 (rate limit) | 데이터 수집 불가 | 요청 간 딜레이, User-Agent 로테이션 |
| Oracle Cloud Free Tier 제한 | 서버 중단 | 리소스 모니터링, 필요시 유료 전환 |
| Playwright ARM 호환성 | 크롤링 불가 | Selenium fallback, x86 에뮬레이션 |
| 예측 정확도 부족 | 사용자 이탈 | 백테스트 철저, ML 모델 단계적 적용 |
| Play Store 심사 거절 | 출시 지연 | 도박 관련 정책 검토, 예측/분석 도구로 포지셔닝 |
| 경주 직전 변경 감지 누락 | 잘못된 예측 제공 | 10분 간격 크롤링 + 수동 새로고침 제공 |
